# StructureML

Production landing page for **StructureML**, an independent research initiative exploring foundational machine learning for structured data.

The complete V0 content, legal, visual, engineering, and release contract lives in [docs/structureml-v0-spec.md](docs/structureml-v0-spec.md). Read it before changing public copy, founders, links, positioning, or architecture.

Application work is developed on feature branches. No public repository or deployment is configured by this project.
